# FrameTx Toolkit + vFrames — announcement draft

Built **FrameTx Toolkit + vFrames** for experimenting with Ethereum frame transactions (EIP-8141).

FrameTx Toolkit: patched Solidity, Foundry, and revm, with account/paymaster examples.

vFrames: a Sepolia playground powered by a Solidity EntryPoint—no FrameTx hardfork required. Drag frames like Lego, then sign, simulate, and submit.

Try an account starting with USDC and zero ETH: authorize execution → swap → pay gas from the output. The submitting EOA still pays network gas and receives reimbursement.

Demo: https://vframes.taek.tech
Code: https://github.com/leekt/FrameTx-toolkit
